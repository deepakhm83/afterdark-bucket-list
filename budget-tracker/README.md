# Afterdark Budget Tracker

Open `index.html` in a browser to use the tracker. Entries are stored in that browser's local storage and are not sent to a server. Use **Download backup** regularly if you want a copy or want to move your data to another device; choose **Import backup** on the other device.

The folder also includes a web app manifest, offline service worker, and icons. To install it as an iPhone Home Screen app, the files need to be hosted at an HTTPS address first. Publishing the app files does not publish the entries stored in a user's browser.
